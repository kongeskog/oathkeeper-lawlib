# Coverage matrix — developer snapshot 4

All rows are **Unreviewed** legally. Source integrity is a separate, time-specific
audit; rerun `sources check` against the referenced bytes. No table cell claims
exhaustive discovery of relevant law.

`not_investigated` fields identify areas without a completeness claim. Model
availability is representation support, not executable legal coverage.
